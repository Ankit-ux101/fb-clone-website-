# Facebook Clone

A full-stack Facebook clone built as a learning project.  
This repository contains a step-by-step tutorial to help you build a modern social media application from scratch.

![Preview](./screenshots/preview.png)

---

## Features

- User Authentication (Sign Up / Login / Logout)
- Create, Read, Update & Delete Posts
- Like & Comment on Posts
- Real-time Feed
- User Profiles
- Image Upload
- Responsive Design (Mobile + Desktop)
- Dark Mode (optional)

---

## Tech Stack

**Frontend**
- React.js
- Tailwind CSS / Material UI
- React Router
- Axios / Fetch API

**Backend**
- Node.js + Express
- MongoDB + Mongoose
- JWT Authentication
- Cloudinary (for image uploads)

**Other Tools**
- Vite / Create React App
- Postman
- Git & GitHub
